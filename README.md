铲子
铲子可清除杂草、翻耕土壤，且可以右键收获作物,回收种子。
强化铲子
强化铲子除了铲子的功能外，如种子回收所述，在高抗性时产出显著更多种子。
洒水壶
洒水壶为作物架洒水增加储水，而水源方块对作物架储水没有任何影响，初次使用时需要右键水源方块进行补充。
植物透镜
植物透镜是早期的关键工具之一。右键点击作物架可查看作物的多项信息。
这些信息包括种类、属性、等级、是否可生长（部分作物有特殊要求）、是否可收获以及生长进度。
